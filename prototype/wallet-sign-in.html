Wallet sign-in · design proposal

October 17, 2026. Proposal for replacing the shared API token with per-user sign-in using an EVM wallet (Sign-In with Ethereum). Synthetic people and addresses; Graphite theme. Layout and copy are for the owner to refine; nothing here is implemented. See docs/architecture/multi-user-wallet-auth.md.

6Edge states

Each failure says what happened and offers the next step, in the card's body. The server returns stable codes; the browser owns the wording, as with credential errors today.

Signature declined

Nothing was signed. Try again or choose another wallet.

Request expired

Sign-in requests last five minutes. Start a new one.

Wallet switched account

Rabby now uses . Sign with the address you connected, or start again with the new one.

Invitation needed

This server only admits invited wallets. Ask its operator for a code.

Smart-contract wallet

Safe and other smart accounts can't sign in yet. Use a regular wallet address.

Too many attempts

Wait a moment before trying again.

No browser wallet found

Install a wallet extension, or scan with a phone wallet.

Journal suspended

The operator of this server has suspended this journal. Contact them to restore access.

Vessel is unreachable

The server didn't answer. Your wallet wasn't asked to sign anything.

9Link another wallet

Linking first asks a wallet that is already linked for a fresh signature (step-up), so a stolen session cannot add an attacker's wallet. Then the same selector in a dialog and a signature from the new wallet with a distinct statement. A wallet that already signs in to another journal is refused.
