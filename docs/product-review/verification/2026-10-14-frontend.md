### Repeat-run differences

The [repeat comparison](2026-10-14-frontend/baseline-repeat-comparison.json)
compares two runs of the same baseline. All 40 image dimensions match. In 32
pairs, no pixel difference exceeds the comparison script's threshold of 24
summed RGBA channel values. Eight pairs exceed it, with changed-pixel ratios
from 0.002% to 2.738%.

This is not proof that those images are byte-identical or that every difference
is harmless. Final visual verification must inspect differing regions, separate
timestamp and rendering noise from UI changes, and explain intended changes.
The current baseline set does not contain separate expanded-entry-dialog shots.
